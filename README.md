Project Two 

The purpose of the Airgead Banking project was to create a C++ application that helps users understand how investments grow over time through compound interest.  The program allows users to enter an initial investment amount, monthly deposits, annual interest rate, and investment duration. It then generates reports showing investment growth with and without monthly deposits.  This project solves the problem of helping users visualize the long-term effects of saving and investing money, making financial concepts easier to understand for students and future investors.


One area I performed well in was implementing object-oriented programming concepts.  I organized the program into classes and functions that separated user input, calculations, and report generation. This made the code easier to follow and reduced duplication.  I also paid close attention to the financial calculations to ensure the compound interest formulas were implemented correctly.  Additionally, I created a user-friendly interface that clearly displayed the investment information and generated readable reports.


One improvement I could make would be strengthening input validation.  While the program accepts user input, additional checks could ensure users cannot enter invalid values such as negative numbers or non-numeric characters.  I could also improve the design by separating calculations into additional helper functions and possibly storing results in data structures for future reporting features. These enhancements would make the application more secure, reduce the chance of errors, improve efficiency, and make future updates easier to implement.


The most challenging aspect of the project was implementing the monthly compound interest calculations and ensuring the yearly reports displayed accurate balances and earned interest. It was important to correctly calculate interest each month and accumulate the values over multiple years. I overcame this challenge by breaking the problem into smaller steps, reviewing the project requirements carefully, and testing calculations with sample values.


Several skills developed during this project will transfer directly to future coursework and software development projects.  These include object-oriented programming, creating and using classes, designing functions, implementing loops and conditional statements, validating user input, and debugging code.  I also strengthened my ability to analyze requirements and translate them into a functioning application. These skills will be useful in future programming, software engineering, and application development courses.


I made the program maintainable and readable by following consistent naming conventions, separating functionality into classes and functions, and including comments throughout the code to explain important logic.  I used meaningful variable and function names so the purpose of each section was clear.  The object-oriented design also made the program adaptable because new features, such as additional investment calculations or report formats, could be added without significantly changing the existing code structure. 


Overall, the Airgead Banking project provided valuable experience applying object-oriented programming principles to solve a real-world financial problem.  Through developing the application, I strengthened my technical skills in C++, problem-solving, debugging, and software design while also learning the importance of writing maintainable and scalable code.  The project demonstrated how software can be used to educate users and support informed financial decision-making.
